# tmux-workplace declaration layers

The shared Structure, Access, Agents and Host layers describe an invented workplace. The accepted Typify reader at `4bb7584a88a4e59bd1295f56f771a3f434e5d7ea` checks the programs and prints a plan. The workplace loop interprets its six executable primitives. This branch is an authoring fixture, not a deployed workplace.

The four complete layer bodies are assembled in that order into `LanguageDeclarations.typify`. Their source intervals are recorded in the fixture's `layers.json`. Layers contain no workplace identity, filesystem root or chosen clearance number. Source files contain no comments.

Under frame sections 5.17 and 5.18, Access prints `statement A B C SCOPE PATH STATE`, `clearance A B C SCOPE NUMBER` and `label PATH NUMBER`. A line produces one recorded state term. Scope is a literal supplied by the layer; file-template captures provide the structural names. No wide line is expanded per seat. Auxiliary shadow cells are bookkeeping for the native reader: the fold must consume all recorded events, including equal duplicates and conflicting statements, rather than the cells' coalesced values. Access declares no join, claim or view cell and performs no root-row check. The frame folds scopes, clearances and labels, and rejects missing roots and policy contradictions.

A flat kinds registry declares each name once. Kind statements are keyed by that name in their own program. A seat selects a registered kind or `none`; native ensures reject unknown kinds and require a selection for every declared directory. Two selectors, their counts and mutually exclusive marker cells reject missing, duplicate or mixed selections without treating `none` as a kind. A seat's generated stores are ordinary seat statements.

The reference fixture keeps Harbor/Orchard's two offices, three rooms and five seats. It uses the fixed root `/tmp/workplace-reference-s3`, two kinds, all five path states, office/room/seat/default clearances, all four label interactions, same-path and ancestor replacements, and bans at all three narrower scopes. Equal workplace statements exercise provenance aggregation. Root and server name are generated data; the ordinary source tree has no additional directory to encode a scope word.

The executable interface remains `server`, `session`, `window`, `pane`, `arrange`, `start`. Its apply order is fixed by the binding. Native program and origin paths remain relative provenance; resource paths are absolute. The unchanged Structure body checks display-name uniqueness but does not independently reject different display names sharing a seat key; the consumer retains its structural checks. Directory context and environment inheritance are unchanged.

`PLAN/plan.json` is the reader's raw output from committed sources. `PLAN/manifest.json` binds those sources and the output hash. No declaration reads a fact, so the native `facts` member is `none` and this fixture requires no facts collection. The independent expected fold and refused variants are deliberately kept outside this repository until SW has implemented the fold from the definition alone. Acceptance of the folded result and loop integration remain separate stops.

For isolated integration, prepare a new `/tmp/workplace-reference-s3` from `root/`, put `tmux.conf` in its `config/`, the assembled declaration and four layers in `config/sources/`, `source/` in `config/sources/tree/`, and `PLAN/` in `config/PLAN/`. Never replace an existing workplace. The integration runner uses its own named tmux server; no command here starts one.
